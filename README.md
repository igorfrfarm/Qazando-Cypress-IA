# Cypress E2E Boilerplate

Pequeno projeto de exemplo com testes E2E em Cypress.

Install:

```bash
npm install
```

Prerequisite:

- Node.js >= 18

Open tests (GUI):

```bash
npm run cypress:open
```

Run tests headless:

```bash
npm run cypress:run
```

Shortcut:

```bash
npm test
```

Note: in CI environments prefer `npm ci`.
